# 各國資料重複檢查（2026-10-08）

已完整掃描17份官方來源的900,831原始列（扣除日本5列標題後900,826資料列），沒有刪除或合併任何原始資料。原始下載檔 checksum、候選列數及 SQLite integrity 均驗證。逐來源統計見 COUNTRY_DUPLICATE_COUNTS.md，完整稽核 JSON 見 country-duplicate-report.json。

## 已確認的重複／重疊

- 台灣 TFDA 成分資料：347個同內容額外列；ATC分類資料：262個同內容額外列。加拿大 DPD 成分資料：175個同內容額外列。共784列，指解析後全部欄位相同的額外出現次數，不能直接稱為784個重複藥品。
- 日本第五份清單的12,428個藥價代碼完全包含於前四份清單。前四份之間没有同碼重疊，各份內也没有重複代碼。五份清單總共12,428個不同藥價代碼，不可把24,856個商品資料列宣稱為獨立商品數。代碼屬藥價清單，仍不能自動升級為已驗收的市場商品身分。
- 台灣許可證表72,062列只有66,503個不同許可證字號；3,616個許可證有多列。所有同許可證差異只落在製造商名稱、製造廠廠址、製造廠公司地址、製造廠國別與製程，不是品名／組成內容衝突。應建立同一許可證的製造廠／製程關聯，保留各列來源，不當成多個商品。
- 加拿大商品、法國商品、韓國標準碼、EMA程序資料，以及日本每個檔案，這次未發現完整同內容重複列或檔案內重複來源鍵。這裡的加拿大来源鍵指drug_code；實際DIN另有重複（見下），不能把內部來源鍵不重複當作商品不重複。這只涵蓋已收錄來源版本，不證明全球資料無重複。
- 同一商品多成分、多包裝、多分類會重複父層來源鍵：台灣處方／ATC／AHFS、加拿大成分、法國CIS_COMPO／CIS_CIP。這些關聯不能用父層許可證／商品碼當作刪重鍵。法國欄位依据官方文件：https://base-donnees-publique.medicaments.gouv.fr/download/file/Contenu_et_format_des_fichiers_telechargeables_dans_la_BDM_v4.pdf 。CIS_CIP的CIP13是包裝鍵，CIS是其父層商品參考，不可混用。

## 實際藥品／包裝碼的第二層檢查

加拿大58,324個drug_code對應58,178個非空DIN，其中108個DIN有多個drug_code。107組品名不同、21組公司不同、10組ai_group_no不同、2組人用／獸用class_name不同，不能只按DIN去重或用最近更新日猜目前商品。例：DIN 00002631同時出現Human／Veterinary來源紀錄。全部群組與來源定位進人工核對，原始資料保留。法國20,920個CIP13包裝碼均非空且沒有重複，也沒有同包裝碼多CIS。詳見country-secondary-key-audit.json以及Actions稽核的secondary_identifier_audit。

各市場內同一標準化商品名稱對應不同來源參考的群組：TW 9,976、CA 6,615、FR 118、EMA 51、JP 289、KR 82,800；包含不同規格／包裝／名稱歷史，不能憑同名自動合併。

## 跨國同名需要另外驗收

1,266組商品名稱、1,985組成分文字在至少兩個市場出現。比對只使用Unicode NFKC、大小寫統一、空白整理；保留強度、鹽類、劑型標點，不做模糊比對、翻譯、同義詞或化學等價推論。

這些只是核對線索，不是「相同藥品」證明。跨國不同許可證與包裝要保留不同商品身分；完整成分、強度、途徑、製造商、適用市場仍需證據和真人驗收。日文／韓文與其他語言沒有字面命中，不代表沒有同藥重疊。不能用名稱相同直接合併，不可用名称不同宣稱沒有重複。

稽核SQLite的 exact_duplicate_members、repeated_native_members、cross_market_name_members views 提供每個群組的全部 source_snapshot_id、來源列號、native reference 與 source_locator；source_content_groups 保留內容出現次數及代表列參考，原始出現紀錄全部可追溯，不作 runtime 去重／醫學核准。

## 舊包與新版不能直接相加

舊包111,389商品列中50列為fixture／sample，獨立排除。舊TFDA的66,301個字面許可證全部與本次TFDA重疊；本次多202個許可證，沒有舊包獨有字號。詳見 legacy-duplicate-audit.json。合成未經驗收的整包時不能把舊TFDA與新版商品直接append，應保留來源版本及同許可證的更新關係。此比較只去除首尾空白，不猜許可證別名。

NHI使用不同形式的數字許可證參考，未把它與TFDA文字字號冒充已完成權威對照。舊包已儲存的ingredient pair按兩端排序後没有多rule群組；但原始上游是否被舊建置預先合併、條件／嚴重度／證據是否完整，仍不可由此證明。
